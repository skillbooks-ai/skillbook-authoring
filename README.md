> A practical guide to building high-quality skillbooks — for AI agents helping humans create structured knowledge bases.

This skillbook teaches AI agents how to help humans author skillbooks. It is not a format reference (that already exists at [skillbooks-ai/skillbook](https://github.com/skillbooks-ai/skillbook)) — it is the practical playbook for **building great books**.

## Who This Is For

AI agents that assist humans with skillbook creation. Whether the human is converting an existing book, structuring original content, or automating production with Gutenberg, this skillbook provides the workflow guidance and quality standards needed to produce publish-ready results.

## What You'll Learn

- **Getting Started** — the authoring workflow, choosing source material, project setup
- **Content Strategy** — decomposing sources into sections, deciding page boundaries, organizing flow
- **Writing Pages** — anatomy of a great page, section overviews, cross-references, tag discipline
- **Using the CLI** — every `skillbook` command with practical usage patterns
- **Quality** — self-review checklist, common mistakes, page length tuning, verification
- **Workflows** — manual conversion, Gutenberg automation, iterative authoring, multi-agent collaboration

## This Book Is the Demo

This skillbook follows the exact format it teaches. Browse its structure to see proper section organization, page boundaries, cross-references, tagging, and navigation — all implemented as described.
