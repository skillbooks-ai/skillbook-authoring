# Choosing Source Material

Not all content makes a good skillbook. The best sources have clear structure, domain
depth, and reference value — content that agents will return to repeatedly.

## What Makes Good Skillbook Content

| Good fit | Why |
|----------|-----|
| Technical manuals | Structured, reference-heavy, agents need specific answers |
| Regulations and legal texts | Authoritative, agents need precise lookup |
| Certification study guides | Well-scoped, testable, clearly organized |
| Textbooks with clear chapters | Already structured, natural section boundaries |
| API documentation | Reference-oriented, agents fetch specific endpoints |
| Style guides and standards | Prescriptive rules, agents need exact requirements |

## What Doesn't Work Well

| Poor fit | Why |
|----------|-----|
| Narrative non-fiction | Linear flow doesn't decompose into atomic pages |
| Opinion pieces | No reference value, not useful for lookup |
| News articles | Ephemeral, no lasting utility |
| Content under 20 pages | Too small — just use a single SKILL.md |
| Highly visual content | Markdown can't carry diagrams or interactive elements |

## Evaluation Checklist

Before starting, ask:

- **Is this reference material?** Will agents return to look things up, or is it read-once?
- **Can it be decomposed?** Does the content have natural boundaries between concepts?
- **Is it authoritative?** Does the source carry weight — official documents, expert authors?
- **Is it stable?** Will the content change so frequently that maintenance becomes a burden?
- **Is the scope clear?** Can you define what's in and what's out?

If you answer "no" to two or more, the content may not be a good fit for the skillbook format.

## Licensing Considerations

Verify that the source material can be legally packaged and distributed. Public domain works,
Creative Commons content, and original material are straightforward. Copyrighted works require
explicit permission from the rights holder.
