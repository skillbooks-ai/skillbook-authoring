# Getting Started

This section covers the end-to-end authoring workflow, how to evaluate source material,
and how to set up a skillbook project from scratch.

## When to Read This Section

- You're about to help a human create their first skillbook
- You need to understand the authoring workflow before diving into content
- You want to evaluate whether source material is suitable for a skillbook
- You need to scaffold a new project

## Pages in This Section

- `01-authoring-workflow.md` — The end-to-end process from source material to published skillbook
- `02-choosing-source-material.md` — What makes good skillbook content and how to evaluate sources
- `03-setting-up-your-project.md` — Project scaffolding, directory structure, and initial configuration

Start with `01-authoring-workflow.md` for the big picture, then read the others as needed.
