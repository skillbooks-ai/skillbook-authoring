# Writing Pages

This section covers the craft of writing skillbook content — the anatomy of a great page,
how to write effective section overviews, cross-referencing patterns, and tag discipline.

## When to Read This Section

- You're about to write content pages and want to know the conventions
- You need to write a `00-overview.md` and want examples of good ones
- You want to know when and how to cross-reference between pages
- You need guidance on tagging pages for lookup

## Pages in This Section

- `01-anatomy-of-a-content-page.md` — The structure of a well-written content page
- `02-writing-section-overviews.md` — How to write `00-overview.md` files that aid navigation
- `03-cross-referencing.md` — When and how to link between pages
- `04-tag-discipline.md` — Consistent vocabulary, semantic tags, and TAG-INDEX.json

Read `01-anatomy-of-a-content-page.md` first — it establishes the pattern all other
pages follow.
