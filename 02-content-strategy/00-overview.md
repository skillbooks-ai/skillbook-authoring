# Content Strategy

This section covers how to decompose source material into sections and pages, how to
organize sections for logical flow, and how to handle different types of content.

## When to Read This Section

- You have source material and need to plan how to break it into a skillbook
- You're deciding where to draw page boundaries
- You need to order sections by dependency
- You're working with an unfamiliar content type (regulation vs tutorial vs reference)

## Pages in This Section

- `01-analyzing-source-material.md` — How to read source material with a decomposition mindset
- `02-deciding-page-boundaries.md` — What makes a good atomic page: concept boundaries, not line counts
- `03-section-organization.md` — Logical flow, dependency ordering, and section naming
- `04-content-types.md` — Patterns for technical manuals, regulations, tutorials, and reference works

Read in order. Analysis informs page boundaries, which inform section organization.
