# Workflows

This section covers end-to-end workflows for creating skillbooks — from converting
existing content to orchestrating multi-agent authoring pipelines.

## When to Read This Section

- You have an existing book, manual, or PDF and want to turn it into a skillbook
- You want to understand the Gutenberg automated conversion pipeline
- You need a repeatable write → validate → refine loop
- You're splitting authoring work across multiple agents

## Pages in This Section

- `01-converting-existing-content.md` — The manual path from PDF, book, or manual to skillbook
- `02-automated-conversion.md` — Gutenberg pipeline overview for batch conversion
- `03-iterative-authoring.md` — The write → validate → refine loop for incremental quality
- `04-multi-agent-authoring.md` — Splitting authoring work across agents effectively

Start with `01-converting-existing-content.md` for the manual path, or
`02-automated-conversion.md` if you're working at scale.
