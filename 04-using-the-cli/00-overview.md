# Using the CLI

The `@skillbooks/cli` provides commands for every stage of the authoring workflow —
from project scaffolding to publishing. This section covers each command with practical
usage patterns.

## When to Read This Section

- You need to initialize a new skillbook project
- You're running validation and need to understand or fix errors
- You want to generate TAG-INDEX.json, the TOC, or section overviews
- You're ready to publish

## Pages in This Section

- `01-project-setup.md` — The `skillbook init` walkthrough and what it creates
- `02-validation.md` — Running `skillbook validate`, understanding errors, fixing them
- `03-mechanical-tools.md` — `tag-index`, `toc`, `sync`, `overview`, `count` — deterministic tooling
- `04-publishing.md` — The `skillbook publish` workflow from final check to live

Read `01-project-setup.md` if starting fresh. Otherwise, jump to the command you need.
